# 示例：36 行 BOM 明细的分页录入时序

以一张 36 条子件的示例 BOM（`BOM000000`，合计用量 `77.25`）为例（物料代码与用量均为**合成数据**），记录每一步的命令、视口状态和校验点。

## 环境快照

| 项 | 值 |
|---|---|
| 屏幕 | 1920×1080，任务栏 48px |
| 分屏 | 左窗口 `(0,0,960,1032)` / K3 `(960,0,1920,1032)` |
| K3 窗口 | `ThunderRT6FormDC`，标题 `BOM单 - 新增 - BOM000000` |
| 表格控件 | `ThunderRT6Frame` @ `(977,458,940,459)`，内含两个 `SPR32A70_SpreadSheet` |
| 横滚动条 | `ScrollBar` @ `(977,900,924,17)` → 中心 y=**908** |
| 竖滚动条 | `ScrollBar aid=1` @ `(1900,458,17,443)` |
| 表头 y | 470 |
| 第 1 行 y | **496** |
| 行距 | **16 px** |
| 可见行数 | 25 → 每页 **24** 行 |

右拨 1 次后的列序与坐标：

```
序号 999 | 商品代码 1074 (aid200 left=1043, 点击 x=1090)
         | 商品属性 | 辅助属性 | 单位 | 子类
         | 用量 1394 (aid201 left=1392, 点击 x=1400)
         | 损耗率 1467 | 使用状态 1560
         | 发料仓库 1619 | 发料仓位 1689 | 备注 1742 | 存在替代 1860
```

> x=1760/1800 是「备注」，x=1830/1860 是「损耗率」。**只有 x≈1400 是「用量」。**

## 时序

### ① 分屏 + 横拨 + 标定

```bash
python _snap_split.py
python _k3_fill.py calib     # 归零 → 右拨 1 次 → 横扫标定 → 写 _k3_calib.json
```

截图确认列标题里出现「用 量」。

### ② 第 1 页代码：第 1–24 行

```bash
python _k3_put2.py code 1 24
```

输出 24 行 `OK`（`y` 从 496 递进，步长 16）。截图确认：第 1 行 `1.99.001`，第 24 行 `1.99.024`，第 25 行空白。

### ③ 下滚 20 次

```python
for _ in range(20):
    click(1908, 891); time.sleep(0.09)
time.sleep(0.9); check_dialog(pid, close=True)
```

截图确认视口首行变成**序号 21**。

### ④ 第 2 页代码：第 25–36 行

```bash
python _k3_put3.py code 25 36 21 496     # base_row=21, base_y=496
```

12 行 `OK`。截图确认：第 25 行 `1.99.025`，第 36 行 `1.99.036`，第 37 行起空白。

### ⑤ 上滚 30 次回顶部

```python
for _ in range(30):
    click(1908, 468); time.sleep(0.09)
time.sleep(1.0); check_dialog(pid, close=True)
```

截图确认首行是序号 1。

### ⑥ 固定焦点到用量第 1 行

```python
click(1400, 496)
f = focused(dlg)
assert f[0] == "201", f      # 必须命中用量列
```

### ⑦ 第 1 页用量：第 1–24 行

```bash
python _k3_qty.py qty 1 24 1 496
```

每行先 `click(1400,y)` → 校验 `aid==201` → `^a` `{DELETE}` 输入 `{ENTER}`。截图确认视口合计 **`50.25`**。

### ⑧ 下滚 20 次 → 重新固定焦点 → 第 2 页用量

```bash
# 下滚 20 次，截图确认首行序号 21
click(1400, 496); assert focused(dlg)[0] == "201"
python _k3_qty.py qty 25 36 21 496
```

截图确认全表合计 **`77.25`**，与源数据合计一致。

### ⑨ 核对 + 收尾

- 逐页截图与源表对行核对；
- 表底合计 = `77.25`；
- **不点保存**（保存按钮 `x≈1047, y≈76`），保持「状态：未使用」。

## 中途出错的两处（已修）

1. **x=1790 写进了「备注」列**：第 1 行备注被写成 `1`。清除方式 `click(1790,496) → ^a → Delete → Return`，随后 UIA 焦点落在 `aid=200 name="1.99.002" @ (1043,508)`，确认无副作用。
2. **第 2 行代码被覆盖**：原因同上，误点备注列后输入被 K3 当作代码列编辑。用 `_k3_put2.py coderaw 1.99.002 2` 修回。
