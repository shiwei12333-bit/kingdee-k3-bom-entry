# 操作检查单

> 打印出来贴屏幕边上。每一步做完打个勾，别跳步。
> 本流程的核心风险不是"跑不通"，而是"跑通了但写错了格子还不报错"。

## 阶段 0 · 开工前

- [ ] 今天要录的 BOM 已经在 **测试账套** 或已确认过的账套里打开
- [ ] 明细表是**空白**的（没有上一批残留行）。若非空白：`python _k3_newbom.py reset`，点「否」
- [ ] 单据头（BOM 编号、父项物料、版本号、数量）已核对，且**不打算**让脚本改它
- [ ] `data.json` 已准备好，行数与源表核对一致
- [ ] `TOTAL_EXPECT` 已知（Σ用量），记下来，最后要对比
- [ ] 关闭微信 / QQ / 邮件 / 系统更新 / 屏保 / 通知中心
- [ ] 输入法切到**英文**（中文输入法会吞掉 `^a`、`{ENTER}`）
- [ ] 不要碰鼠标键盘 —— 脚本跑的时候任何手动操作都会打乱焦点

## 阶段 1 · 环境

- [ ] `python _snap_split.py` → 打印 `left=... K3=... FG=...`，两半宽度接近相等
- [ ] 截图确认：K3 在**右半屏**，明细表可见
- [ ] 数一遍可见行数 `V`，算出 `PAGE_ROWS = V − 1`
- [ ] 量一次相邻两行的 y 差，确认 `ROW_H`

## 阶段 2 · 视口

- [ ] `python _k3_fill.py hscroll right 1`
- [ ] **截图确认能看到「用量」列标题**（看不到就别往下走）
- [ ] `python _k3_fill.py calib` → 记录 `X_CODE` / `X_QTY` / `QTY_LEFT`
- [ ] 手工点一次 `(X_QTY, Y1)`，截图确认光标在**用量**格（不是备注、不是损耗率）

## 阶段 3 · 填代码

- [ ] `python _k3_put2.py code 1 <PAGE_ROWS>`
- [ ] **截图确认本页代码全对**（逐行看，别只看行数）
- [ ] `python _k3_fill.py scroll down 20`
- [ ] 截图确认视口首行**序号** → 记作 `base_row`，第一行 y 记作 `base_y`
- [ ] `python _k3_put3.py code <base_row> <base_row+PAGE_ROWS-1> <base_row> <base_y>`
- [ ] 截图确认 → 重复滚动 + 录入，直到全部代码填完
- [ ] **全部代码填完后截一张总览图**，确认最后一行之后是空白行

## 阶段 4 · 填用量

- [ ] `python _k3_fill.py scroll up 30` → 回到序号 1
- [ ] 截图确认当前在序号 1
- [ ] 重新确认 `(X_QTY, Y1)` 是**用量**格（换页后列位置可能变）
- [ ] `python _k3_qty.py qty 1 <PAGE_ROWS>`
- [ ] **截图确认本页用量全对**
- [ ] `python _k3_fill.py scroll down 20` → 截图确认首行序号
- [ ] `python _k3_qty.py qty <base_row> <base_row+PAGE_ROWS-1> <base_row> <base_y>`
- [ ] 截图确认 → 重复直到全部用量填完

## 阶段 5 · 终检（最关键）

- [ ] 滚到最顶，截图；滚到最底，截图
- [ ] **逐行比对**：物料代码对得上源表、用量对得上源表
- [ ] 视口合计 = `TOTAL_EXPECT`（脚本会打印每屏合计，两屏相加）
- [ ] 检查**备注列**没有被误写数字（`x≈1742~1800` 那列）
- [ ] 检查**损耗率列**没有被误写数字（`x≈1830~1860` 那列）
- [ ] 检查「使用状态」是否都是预期值
- [ ] 检查有没有空行夹在中间

## 阶段 6 · 交给人

- [ ] **不点保存**。脚本从头到尾不点保存，这一步是给操作者的提醒
- [ ] 把截图和总览发给负责核对的人
- [ ] 由人决定是否保存、何时保存
- [ ] 保存后复核：BOM 明细行数、合计用量、有无重复行

## 出问题时的止损顺序

1. **立刻停手**，不要再点任何格子
2. 截图存证（当前视口 + 弹窗）
3. 有弹窗先去关弹窗（点「确定」/「否」），别点「是」
4. 判断污染范围：只错一行 → 单格 `ctrl+a` → `DELETE` 重录；多行错位 → `ctrl+z` 或整单重置
5. `ctrl+z` 弹出的「将撤销当前改动，是否需要恢复?」**点「否」**（点「是」不会帮你恢复，只会更乱）
6. 重置后**重新标定**（窗口可能已经变了），别拿旧坐标继续

## 三条铁律（贴在最后）

1. **永不发 ESC** —— ESC = 取消当前格的输入，不是退编辑态。
2. **永不靠 `focused()` 判断列身份** —— 无弹窗时读的是陈旧缓存，会骗你。
3. **永不点保存** —— 这是这套流程唯一的安全边界。
